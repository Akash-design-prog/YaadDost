Normalization is the process of organising a database to reduce redundancy and avoid update anomalies.
1NF: every column holds atomic values and there are no repeating groups.
2NF: the table is in 1NF and no non-key column depends on only part of a composite primary key.
3NF: the table is in 2NF and no non-key column depends on another non-key column (no transitive dependency).
BCNF is stricter than 3NF: for every functional dependency X -> Y, X must be a superkey.
A primary key uniquely identifies each row and cannot be NULL.
A foreign key links a column in one table to the primary key of another table.
